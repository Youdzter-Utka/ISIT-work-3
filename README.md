# Задача № 3: военный или гражданский самолёт — бесплатный Google Colab

[![Открыть в Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Youdzter-Utka/ISIT-work-3/blob/main/report.ipynb)

**Запуск в браузере. HF-токен, кредиты Hugging Face, платные API и установка программ на компьютер не нужны.**
Две открытые мультимодальные LLM скачиваются с Hugging Face и работают в среде Google Colab:
**SmolVLM-500M-Instruct** и **Qwen2.5-VL-3B-Instruct**.
Файл `report.ipynb` — формат документа, который открывает Colab; устанавливать Jupyter или Anaconda не нужно.

## Как запустить
1. Нажмите **Открыть в Colab** и сохраните копию на Google Диске.
2. Выберите **Среда выполнения → Сменить среду выполнения → T4 GPU** (бесплатный GPU, если доступен).
3. Выберите **Среда выполнения → Выполнить всё**. Первый запуск скачает исходники, библиотеки и несколько гигабайт весов моделей.
4. Дождитесь таблицы метрик, матриц ошибок и вывода внизу документа.
5. Последняя ячейка скачает ZIP с реальными ответами, таблицами и графиком. Сохраните также выполненный notebook.

Ничего вручную клонировать, загружать, вводить в Secrets или править в коде не нужно.
Бесплатный GPU Colab предоставляется по доступности, его квота ограничена. Если GPU не выдан,
notebook остановится с понятным сообщением: попробуйте позже. CPU-запуск предусмотрен, но намного медленнее;
для него нужно осознанно установить `ALLOW_CPU=True`. Платный план не требуется.
Покупка Colab Pro не предусмотрена этим проектом.

## Что сравнивается
- 30 фотографий: 15 military, 15 civilian; 20 заранее помечены как сложные.
- Основное назначение модификации: вооружённый оператор сам по себе не делает гражданскую конструкцию военной.
- Фото и промпт одинаковые; используется greedy decoding без обучения и настройки на тестовых ответах.
- Модели запускаются по очереди, чтобы не занимать GPU-память одновременно.
- Accuracy, macro-precision/recall/F1, метрики по классам, качество на сложных фото, доля валидных ответов и время обработки.
- Невалидный ответ считается ошибкой. Таблица сравнения строится только после всех 60 предсказаний.
- Каждое предсказание сохраняется сразу. Повторный запуск в той же среде пропускает готовые ответы.

**Статус:** бесплатный вариант подготовлен; реальное выполнение этих двух моделей в Colab ещё не проведено.
Значения метрик не подставлены. Тестовые ответы в репозиторий не включены.

## Соответствие исходному заданию
В исходной формулировке упомянуты «провайдеры LLM на Hugging Face». Здесь используется
**загрузка моделей с Hugging Face и выполнение в Colab**, а не платный сервис **Inference Providers**.
Это согласованная с пользователем бесплатная редакция. Если преподаватель требует именно Inference Providers,
способ запуска нужно согласовать; нельзя выдавать его за вызовы провайдеров.

## Файлы
| Файл | Назначение |
|---|---|
| `report.ipynb` | Основной документ Colab: запуск, галерея, объяснения, метрики и полный исходный код |
| `src/experiment.py` | Загрузка моделей, генерация ответов, возобновление и оценка |
| `config.json` | Две модели с закреплёнными версиями, параметры |
| `requirements.txt` | Библиотеки для временной среды Colab |
| `data/manifest.csv` | Метки, сложность, авторы, лицензии, ссылки и SHA-256 |
| `data/images/` | 30 уже проверенных JPEG |
| `results/status.json` | Текущий статус; после запуска обновляется |

После запуска в `results/` появятся `predictions.jsonl`, `experiment.json`, `metrics.csv`,
`per_class_metrics.csv`, `all_predictions.csv`, `errors.csv`, `confusion_matrices.png`, `summary.json`.
Скачать папку можно последней ячейкой notebook. Временная среда Colab может удалиться при отключении:
сохраняйте ZIP результатов. В notebook есть необязательное восстановление ранее скачанного ZIP.
Изменение моделей, версии среды, промпта или данных требует отдельного журнала эксперимента.
